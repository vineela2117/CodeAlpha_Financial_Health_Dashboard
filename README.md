# Financial Health Dashboard

## Project Overview
This Power BI dashboard was developed as part of the CodeAlpha Internship Program. The project focuses on analyzing an organization's financial performance through interactive visualizations and key financial metrics.

## Objectives
- Analyze income statements
- Monitor balance sheet performance
- Track cash flow trends
- Evaluate profitability over time
- Support financial planning and decision-making

## Tools Used
- Power BI
- Microsoft Excel
- GitHub

## Features
- Interactive Dashboard
- Revenue Analysis
- Profitability Tracking
- Cash Flow Monitoring
- Financial KPI Visualization
